# Phase 2 Web Screen Catalog

**Platform:** React + TypeScript + Vite + Tailwind + Router + Query  
**Common shell:** authenticated header, Gym context, sidebar, request/error boundary, RTL locale switch, accessible dialogs, print/PDF actions where listed.

`API` names are defined in `04_API_ENDPOINT_CATALOG.md`. `Source` identifies TOP GYM parity evidence, Master Bible scope, or LogicFit architecture/new feature.

## Explicit Web-only screens

Platform infrastructure, global migration, backup/restore, deployment/monitoring, full POS, inventory operations, access administration, and report configuration are Web-first. They are not duplicated in Flutter without a separately approved mobile use case.
