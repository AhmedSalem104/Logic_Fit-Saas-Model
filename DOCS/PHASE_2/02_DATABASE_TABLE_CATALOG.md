# Phase 2 Database Table Catalog

This catalog is the canonical design inventory. It lists every table proposed by the Phase 2 contracts, its purpose, scope/source, core fields, relationships, indexes/checks, security/consumers, and migration note. It is a contract, not executable SQL.

## Field notation

- `PK` = server-generated `uniqueidentifier` primary key.
- `FK` = same-database foreign key unless explicitly marked `CP-REF` (Control Plane reference without a cross-database FK).
- `AUDIT` = shared audit columns from `01_DATABASE_CONTRACT.md`.
- `RV` = SQL Server `rowversion`.
- `SOURCE` values identify TOP GYM evidence, Master Bible requirement, approved decision, architecture requirement, or new LogicFit feature.
